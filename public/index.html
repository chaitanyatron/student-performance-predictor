About the algorithm

Decision Tree

A Decision Tree asks a series of yes/no questions such as “Is Previous_Marks ≤ 65?”. Each answer sends the student down a branch until a leaf gives the final class. At each step scikit-learn picks the question that best separates the classes (measured by Gini impurity).

Methodology

  1. Load and validate the CSV (500 synthetic students, 6 features, 3 classes) using pandas.
  2. Convert Participation_Level (Low / Medium / High) into 1 / 2 / 3.
  3. Split into 80% training and 20% test data (fixed random seed, stratified by class) before training, so the test data is never seen by the model.
  4. Train a Decision Tree with max_depth=4 to keep it small and explainable.
  5. Predict the test students and compute accuracy and the confusion matrix from those predictions.

Limitations

  • The data is synthetic (randomly generated), so results show the method, not real student behaviour.
  • Only 500 records and 6 features; real performance depends on many more factors.
  • A single Decision Tree can be unstable — small data changes may produce a different tree.
  • Predictions are estimates and must not be used to make decisions about real students.
